# Northstar Markets · 美股合约 ETF 演示原型

这是一个可本地运行、可由后台编辑配置的前后台网页原型。它只使用模拟行情、模拟项目和虚拟积分，USDT 充值/提现只记本地演示流水，不连接链上钱包、券商或真实身份服务。

## 本地运行

```bash
npm install
npm run dev
```

- 前台：<http://127.0.0.1:5173/>
- 后台：<http://127.0.0.1:5173/admin>
- 本地管理员密钥：`local-demo-admin`

## 后台可编辑项

- 前台品牌名、市场概览文案、延时行情标注和模块入口开关
- ETF 标的和指数卡片数据
- 时间合约期限及虚拟结算比例
- 预测事件题目、分类、模拟概率与截止时间
- 模拟 USDT 网络、最低提现额和手续费
- SIM 项目与展示曲线、KYC 和提现审核队列

设置会在前台约 5 秒内自动同步。当前 API 和记录使用进程内存，重启后恢复默认设置并清空演示记录。

## 公网部署准备

项目包含 Vercel 配置。部署前必须在托管服务设置一个高强度 `ADMIN_REVIEW_KEY` 环境变量；生产环境不会允许使用本地默认密钥。可参考 `.env.example` 创建本地配置，但不要把 `.env` 提交到公共仓库。

本地 API 使用 Express，Vercel 会将 API 作为函数运行。当前演示数据不持久化；若要长期公开使用，需要先接入数据库、可靠的登录系统、服务端权限控制、正式 KYC 与支付服务。不要在此演示站填写真实个人资料、证件或转入真实 USDT。

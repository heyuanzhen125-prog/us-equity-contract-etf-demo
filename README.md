# Northstar Markets · 美股合约 ETF 演示原型

这是一个可本地运行、可由后台编辑配置的前后台网页原型。它只使用模拟行情、模拟项目和虚拟积分，USDT 充值/提现只记本地演示流水，不连接链上钱包、券商或真实身份服务。

## 本地运行

```bash
npm install
npm run dev
```

- 前台：<http://127.0.0.1:5173/>
- 后台：<http://127.0.0.1:5173/admin>
- 核心 API 回归测试：`npm test`
- 后台 USDT / USDC 充值配置：登录后在后台左侧导航选择「USDT / USDC 充值配置」，与其他后台功能共用同一端口和会话
- 本地管理员密钥：`local-demo-admin`

## 后台可编辑项

- 前台品牌名、页面标题说明、导航/按钮文案、延时行情标注和模块入口开关
- ETF 标的和指数卡片数据（表单编辑，无需编辑代码或 JSON）
- 时间合约期限及虚拟结算比例
- 预测事件题目、分类、模拟概率与截止时间
- USDT / USDC 演示充值网络、地址、二维码链接、最低金额和说明
- 模拟 USDT 提现限额与手续费
- SIM 前台项目列表：新增、编辑、排序、上下架和删除
- SIM 模拟项目可设置 20 个行情价格点及每点 1–60 秒切换间隔；前台逐点播放并线性过渡，不参与订单结算
- 后台「输赢结果控制」可按全体或个人 ID 设置时间合约与事件预测的虚拟输赢，覆盖未结算记录及后续新记录
- 后台输赢控制页显示最近 300 笔前台订单，可逐单设置或更改时间合约、合约 ETF、事件预测结果
- 事件预测投入虚拟积分（默认 100 分，可在 10–1000 分内设置）；赢时按事件收益比例返还本金和收益，输时扣除投入
- 合约 ETF 模拟买卖单会记录到个人账户；按预估金额扣虚拟美元，赢时按后台收益比例返还本金与收益，输时扣除投入
- KYC 和提现审核队列
- 后台独立人员账号与角色栏目权限；首次登录必须修改临时密码
- 代理资料、下级个人 ID 与可编辑返佣比例

设置会在前台约 5 秒内自动同步。输赢结果控制只作用于虚拟演示积分和记录，不涉及真实资金、真实市场或 SIM 行情点位。当前 API 和记录使用进程内存，重启后恢复默认设置并清空演示记录（包括后台人员账号、角色、代理资料及会话）；生产使用前需接入持久化数据库。
USDT 与 USDC 演示余额分开记账。充值配置沿用运营后台登录状态；页面结构和样式固定，日常内容与项目管理可在后台表单中完成，无需编辑代码。前后台支持按主机名分流：未配置域名时沿用 `/admin`；购买域名后可把前台域名和后台域名添加到同一个 Vercel 项目，并设置 `VITE_FRONTEND_URL` 与 `VITE_ADMIN_URL`。之后前台上的后台入口会跳到后台域名，旧的 `/admin` 链接也会自动跳转；后台“返回前台”会回到前台域名。两个域名由同一份代码自动部署。
代理返佣当前保持待接入状态：没有真实入金数据源，因此后台不会从演示充值自动生成佣金，也不会进行资金结算。接入并验证真实入金 API 后，才能启用“已确认入金 × 代理返佣比例”的自动计算。

## 公网部署准备

项目包含 Vercel 配置。部署前必须在托管服务设置一个高强度 `ADMIN_REVIEW_KEY` 环境变量；生产环境不会允许使用本地默认密钥。可参考 `.env.example` 创建本地配置，但不要把 `.env` 提交到公共仓库。

购买域名后，在 Vercel 项目 Settings → Domains 中添加前台域名和后台域名，并按 Vercel 给出的 DNS 记录完成验证。再在项目环境变量中设置 `VITE_FRONTEND_URL=https://你的前台域名` 和 `VITE_ADMIN_URL=https://你的后台域名`，重新部署即可。`VITE_` 前缀表示这些域名会写入浏览器代码；不要在其中放密钥。

本地 API 使用 Express，Vercel 会将 API 作为函数运行。USDT / USDC 地址和二维码仅作为演示信息展示；“模拟增加余额”不会广播链上交易或确认真实到账。当前演示数据不持久化；若要长期公开使用，需要先接入数据库、可靠的登录系统、服务端权限控制、正式 KYC 与支付服务。不要在此演示站填写真实个人资料、证件或转入真实 USDT / USDC。
